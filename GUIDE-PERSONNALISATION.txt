VROOMY - COMMENT PERSONNALISER (logo, nom, couleurs)
====================================================
Outil conseillé (gratuit) : Visual Studio Code (code.visualstudio.com) ou Notepad++.
Ouvre le dossier "vroomy" dans l'éditeur. Pour tout remplacer d'un coup : Ctrl+Maj+H (Rechercher / Remplacer dans tous les fichiers).

1) CHANGER LE NOM DE L'APPLICATION
   Remplace "Vroomy" (et "VROOMY") par ton nouveau nom, dans ces fichiers :
   - index.html : titre de l'onglet, texte du bandeau en haut, écran de bienvenue, titre de l'app iPhone
   - manifest.webmanifest : "name" et "short_name" (le nom sous l'icône sur l'écran d'accueil)
   - js/app.js : textes "À propos", mentions légales, nom du fichier d'export
   Astuce : fais d'abord "Vroomy" -> "TonNom", puis "VROOMY" -> "TONNOM".

2) LE LOGO OFFICIEL (pin rouge avec la voiture)
   Fichiers dans le dossier assets/ :
     logo-lockup.svg      : logo complet vertical (pin + trajet pointillé + "Vroomy"), écran de bienvenue
     logo-horizontal.svg  : pin + "Vroomy" côte à côte, bandeau en haut de la carte
     icon.svg             : icône de l'application (carré blanc arrondi avec le pin rouge)
     icon-square.svg / icon-maskable.svg : même icône en carré plein, pour iPhone et Android
     icon-192.png, icon-512.png, apple-touch-icon.png (180 px), icon-maskable-512.png : versions image de l'icône
     logo-officiel-icone.svg et logo-officiel-complet.svg : tes fichiers d'origine
   Pour changer le logo plus tard : remplace ces fichiers en gardant EXACTEMENT les mêmes noms.
   Astuce : pour obtenir les PNG à partir d'un SVG, utilise cloudconvert.com ou realfavicongenerator.net.

3) COULEURS ET POLICE (palette du logo : rouge, blanc, encre)
   Ouvre css/style.css. Tout en haut, modifie les variables :
     --blue / --acc / --g1 / --g2 / --grad : le rouge (boutons, interrupteurs, icônes, halos). Rouge du logo : #F50920
     --ink : l'encre (texte, couleur du mot "Vroomy")      --bg : le fond gris très clair      --card : les cartes blanches
     --glow : l'intensité du halo lumineux
   Couleur du trajet sur la carte : dans js/app.js, cherche F50920.
   Police : Poppins, chargée dans index.html.
   Pense aussi à "theme_color" et "background_color" dans manifest.webmanifest.

4) APRÈS TOUTE MODIFICATION
   - Dans sw.js, change "vroomy-v11" en "vroomy-v12" (puis v13...) : ça force les téléphones à recharger la nouvelle version.
   - Remets le dossier en ligne (Netlify Drop : glisse à nouveau le dossier).
   - Sur téléphone, si tu vois l'ancienne version : ferme complètement l'app/l'onglet et rouvre-la. Si tu avais ajouté l'app à l'écran d'accueil, supprime-la et ajoute-la à nouveau pour voir la nouvelle icône.
